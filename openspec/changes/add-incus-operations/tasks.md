- [x] 1.1 Define `Opsmaru.Incus.Operations` descriptors and `all/0` under the approved `incus_<resource>_<verb>` names; verify stable names/schemas via snapshot tests and that each descriptor calls only public client functions. Evidence: `lib/opsmaru/incus/operations.ex` (32 descriptors, `all/0`, `describe/1`); `test/operations_catalogue_test.exs` pins names, schemas, scopes, confirmation and bounds against `test/fixtures/incus/operations-catalogue.json` and checks from the compiled BEAM that every client call is a public, non-hidden function.
- [x] 1.2 Define the `Opsmaru.Incus.Operations.Host` binding; verify missing/failing callbacks, forged connection/owner input and unauthorized projects deny with zero fake-backend requests. Evidence: `Opsmaru.Incus.Operations.Host`; `test/operations_host_test.exs` covers missing/raising/exiting/malformed binding and authorization, forged URL/socket/owner/connection/target input, unapproved image remotes, a not-ready host and an unauthorized project, each with zero fixture requests; the project is selected only after `authorize/3`.
- [x] 1.3 Implement scope and destructive-confirmation enforcement; verify read-only callers, missing or mismatched confirmation and wrong scopes cannot reach the backend. Evidence: `test/operations_host_test.exs` ("scope and confirmation", "restricted create and update input"): every non-read operation denied for a read-only caller, scopes not interchangeable, missing confirmation fails validation, mismatched or inferred confirmation refused, restricted config/devices denied unless the host allows them, all before backend access.

## 2. Operations

- [x] 2.1 Implement inspection operations; verify native data, list/output bounds and truncation against fixtures. Evidence: `test/operations_inspection_test.exs` over Unix and mutual HTTPS: all 20 inspections return native data unchanged (VM-shaped instances, state and volumes, unknown fields), native paths/queries, `limit` truncation with the native total, the 256 KiB output bound (explicit truncation; `output_limit` for one oversized item), native errors and fresh server discovery.
- [x] 2.2 Implement instance create/update/state and snapshot create/restore with bounded wait; verify completed, running, failed and uncertain results with native operation identity and no automatic retry. Evidence: `test/operations_mutation_test.exs`: completed (Unix and mutual HTTPS), running, failed and uncertain (truncated response, one POST, no wait) results with native operation identity; native rejection not retried; wait capped by the connection timeout; a local wait deadline reports running without any DELETE; native create/state/snapshot/restore bodies; conditional PATCH with given or read ETag and native 412.
- [x] 2.3 Implement deletion operations; verify confirmation, native errors and operation identity. Evidence: `test/operations_mutation_test.exs` ("deletion") for confirmed instance, snapshot and full-fingerprint image deletion with operation identity and native errors; confirmation refusals in `test/operations_host_test.exs`.
- [x] 2.4 Implement bounded guest exec; verify explicit instance, argv/env/stdin/output/duration limits, exit status and truncation without an interactive terminal. Evidence: `test/operations_exec_test.exs` against a scripted exec WebSocket peer: native noninteractive body, stdin, exit status and user/group/cwd/env over Unix and mutual HTTPS; 64 KiB truncation with byte counts (UTF-8, trimmed UTF-8, base64); SIGKILL over the control channel at the duration and past the stream cap; stream-timeout cap; argv/env/cwd/stdin/user/timeout/interactive/width bounds with zero requests; another request served during a running command.
- [x] 2.5 Implement operation get/wait/cancel; verify local timeout versus remote cancellation and unsupported cancellation reporting. Evidence: `test/operations_mutation_test.exs` ("operation get, wait and cancel by ID"): rebinding by UUID through GetOperation/GetOperationWait/DeleteOperation, a local wait timeout reported as running with no DELETE, and cancel outcomes already_final, unsupported (no DELETE), requested, uncertain and native 403.
- [x] 2.6 Record per-operation client method evidence; verify operations depending on unevidenced client methods are not exported. Evidence: each descriptor's `requires` and `Opsmaru.Incus.Operations.Evidence`; `test/operations_catalogue_test.exs` checks every exported requirement has evidence and that a descriptor with an unevidenced method is not exported. `coverage.json` is unchanged.
